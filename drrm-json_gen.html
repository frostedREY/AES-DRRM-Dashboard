Purpose. This tool is a helper for the Antipolo ES DRRM Dashboard. It lets an admin fill out a simple form and instantly get a ready-to-paste JSON file, so you never have to hand-write JSON and worry about missing commas or quotes.

Who it's for. The school's DRRM admin who updates the three JSON files hosted on GitHub — announcement.json, school_status.json, and par_status.json — that the dashboard fetches every hour.

How to use it.

  • Pick a file type using the tabs: Announcement, Status, or PAR.
  • Fill in the form, or switch to 📥 Paste mode to load an existing JSON.
  • In the Announcement tab, you can hide either section — the hidden block is omitted from the output entirely, so you get a fragment to paste into the matching spot on GitHub.
  • Tap ⚡ Generate & Copy — the JSON is built, validated, and copied to your clipboard.
  • If you've set a GitHub Edit URL, tap 🚀 Open Edit Page to jump straight to the GitHub editor, then paste and commit.
  • Every generated JSON is auto-saved to 💾 Drafts in the app bar.

Rules to remember. The generator follows the guide: strings in double quotes, no comments, booleans as true/false, numbers plain, and state in ALL CAPS. Always double-check with jsonlint.com before committing.

Be responsible. ⚠️ This is an emergency-communication tool. Only publish information you have verified from official sources such as PAGASA, PHIVOLCS, DepEd, or your school administration. False or premature announcements can cause confusion and put people at risk. When in doubt, confirm first, publish second. Keep messages clear, calm, and factual. For truly urgent, last-minute updates, use the dashboard's long-press local admin panel, then sync the JSON afterward so all TVs pick up the same change.

Thank you for helping keep the school safe and well-informed. 💙
